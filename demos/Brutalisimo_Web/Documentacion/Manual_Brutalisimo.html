MANUAL DE USUARIO

Sistema de Tracking Interactivo
Brutalisimo Shein

¡Felicidades por tu nueva plataforma! Este manual contiene la información necesaria para entender cómo opera el sistema de rastreo de pedidos, las reglas de oro para que no falle y cuáles son los roles tanto de tu empresa como de tus clientes.

1. ¿Qué es y cómo funciona?

Es una aplicación web conectada en tiempo real a tu base de datos (Hoja de cálculo en Google Drive). Su propósito es automatizar la atención al cliente. El cliente podrá entrar a la plataforma, escribir su nombre y saber exactamente dónde está su pedido sin tener que escribirte por WhatsApp, ahorrándote horas de atención manual.

2. Roles del Sistema

🏢 La Empresa (Tú)
  • Actualizar la Hoja de Cálculo en Drive cada vez que un lote avance de estatus.
  • Asegurarse de escribir bien el Nombre y Apellido del cliente en el Excel.
  • Compartir el enlace de la página web (Netlify) en la biografía de Instagram, mensajes de bienvenida de WhatsApp o directamente a los clientes.
🛍️ El Cliente
  • Ingresa a la página web desde su celular o PC.
  • Escribe su Nombre y Apellido (el sistema no distingue mayúsculas o minúsculas, así que es fácil buscar).
  • Obtiene de inmediato el estatus visual de su paquete. Si tiene dudas extra, podrá tocar el botón para ser redirigido a tu WhatsApp.

3. Uso de la Hoja de Cálculo (Matriz)

La hoja de cálculo en Drive es el "Cerebro" de tu aplicación. Es fundamental entender para qué sirve cada columna:

  • Columna Nombre y Apellido: Deben coincidir con lo que el cliente va a buscar. Trata de mantener un estándar (Ej: Maria Perez).
  • Columna Quincena / Lote: Aquí colocas el identificador del pedido. Si pones un número (ej: 7), el sistema en la web dirá automáticamente "Quincena 7". Si escribes un texto (ej: Primera de Mayo), el sistema mostrará ese texto tal cual.
  • Columna Fecha: Se actualiza para saber cuándo fue el último cambio.

⚠️ Los Estatus Oficiales

El sistema dibuja una barra de progreso según el estatus. Para que la barra avance correctamente, debes escribir el estatus en tu Excel EXACTAMENTE como alguna de estas opciones (recomendamos crear una lista desplegable en Excel para evitar errores ortográficos):

  • TRANSITO SHEIN USA
  • LLEGADA CASILLERO MIAMI
  • TRANSITO VENEZUELA
  • LLEGADA ADUANA VENEZUELA
  • TRANSITO ESTADAL
  • LUGAR DESTINO

4. Reglas de Oro

  • No cambies el nombre de la pestaña de la hoja de cálculo (la que está en la parte inferior del Excel), a menos que el desarrollador actualice el código.
  • No elimines columnas existentes. Si necesitas columnas extra para uso interno, añádelas a la derecha de las que ya existen, pero nunca borres las columnas de Nombre, Apellido o Estatus.
  • No elimines ni modifiques el código Apps Script que vincula el Excel con la web, ya que esto romperá la comunicación.

5. Sistema de Suscripción (Seguridad)

La plataforma cuenta con un mecanismo de conexión hacia el servidor del Desarrollador. Si la licencia de uso o suscripción de mantenimiento se marca como "INACTIVA" por falta de pago, la plataforma mostrará automáticamente un bloqueo de "Servicio Suspendido" impidiendo el acceso a los clientes finales. Al regularizarse el estatus, el sistema vuelve a operar en milisegundos.
